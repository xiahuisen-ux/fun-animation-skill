# 趣味动画 Skill

一句口播，演成一场戏。想想想 AI 做的「趣味动画 Skill」会从主题、口播、字幕或底片里挑出最值得演的一句，想几种不同演法，再写清楚角色怎么动、物件什么时候碰到、画面最后变成什么样。

[下载 fun-animation.zip](https://github.com/xiahuisen-ux/fun-animation-skill/raw/refs/heads/main/fun-animation.zip)

## 怎么用

1. 下载 ZIP，在支持导入自定义 Skill 的应用里上传。在豆包工作或 WorkBuddy 的技能管理页，找「添加」或「上传技能」。也可以解压后，按应用要求导入含 `SKILL.md` 的文件夹。
2. 在新任务里选中 `fun-animation`，给它你的文案、字幕或底片。
3. 先选一个关键句做小试片，再把满意的动画插进合适的位置。交给有视频生成或剪辑工具的环境，可以继续制作和合成。

可以用这条指令试一下。

> 用趣味动画 Skill，从这段口播里挑一句最值得演的话。给我两种不同的演法，写清动作的开始、触发、反应和结果。选一版做三秒试片，保留原声和字幕。

例如「工作压力把我按在地上摩擦」，可以让文档、网页和 BUG 接连砸下来，人物抱头趴回地面。观众看着动作发生，就读懂了那句话。

ZIP 根目录包含 `SKILL.md` 和 `references/`，可直接作为技能安装包使用。
